# ModelHub（Seedance 视频）

在 Dify 里通过 [ModelHub](https://modelhub.cc) 生成 Seedance 2.0 / 2.5 视频。

ModelHub 是独立的 API 服务，与字节跳动没有关联，也未获其背书；插件名里的模型名只用来说明调用的是哪个模型。

- **作者：** modelhub-cc
- **版本：** 0.0.1
- **类型：** 工具（tool）
- **源码：** https://github.com/modelhub-cc/modelhub-dify-plugin
- **联系：** lakers202601@163.com

## 功能

| 工具 | 作用 |
|---|---|
| 生成视频 | 用提示词生成视频，可加参考图、参考视频、参考音频（文件或 https 链接），或首尾帧。最多等待 8 分钟，直接返回视频文件。 |
| 查询视频任务 | 按任务 ID 查询，完成后取回视频。任务状态为 `processing`、`completed`、`failed`、`cancelled` 之一；失败和已取消都会直接结束并给出 ModelHub 返回的原因。查询免费。 |

| 模型 | 时长 | 分辨率 | 参考素材上限（图 / 视频 / 音频） |
|---|---|---|---|
| `seedance-2.0-mini`（最便宜） | 4～15 秒 | 480p、720p、1080p | 9 / 3 / 3 |
| `seedance-2.0-fast` | 4～15 秒 | 480p、720p、1080p | 9 / 3 / 3 |
| `seedance-2.0` | 4～15 秒 | 480p、720p、1080p | 9 / 3 / 3 |
| `seedance-2.5` | 4～30 秒 | 480p、720p、1080p | 30 / 10 / 10 |
| `seedance-2.5-flash` | 4～30 秒 | 480p、720p | 10 / 5 / 5 |

比例 16:9、9:16、1:1、4:3、3:4、21:9。默认同时生成声音（2.5 Flash 没有声音开关）。

## 配置

1. 在 [modelhub.cc](https://modelhub.cc) 注册并充值积分。
2. 在 ModelHub 控制台创建 API Key（以 `pk_` 开头）。
3. 在 Dify 的「插件」里安装 **ModelHub（Seedance 视频）**，点「授权」粘贴 Key。保存时会校验 Key，校验不会创建任务，也不扣费。
4. 在工作流、Chatflow 或 Agent 里添加「生成视频」工具。

## 使用

- **文生视频：** 填提示词，选模型、时长、分辨率。
- **全能参考：** 参考图（JPEG/PNG/WebP，人物、产品、场景）、参考视频（MP4/MOV/WebM，动作、运镜、风格）、参考音频（MP3/WAV/M4A/AAC/OGG/FLAC，音色、配乐、节奏）可以组合使用。每类都可以上传文件或填公开 https 链接（逗号或换行分隔），文件和链接合计不超过上表的上限，编号先文件后链接。ModelHub 还可能限制一次请求里图、视频、音频的总数，超出时会直接拒绝（HTTP 4xx，不扣费）并给出提示。提示词里说明每个素材的用途，比如「图1的女生拿着图2的瓶子，动作参考视频1」。
- **在提示词里引用素材（可选）：** 全能参考模式下，可以用 `@image_file_1`、`@video_file_1`、`@audio_file_1` 等指定某个素材，比如「@image_file_1 从 @image_file_2 的门口走进来，动作参考 @video_file_1」；中文写法 `@图1` 也可以。编号要从 1 开始连续，顺序同上（先文件后链接）。不写 `@` 引用也能出片。
- **首尾帧：** 上传「首帧」，可选「尾帧」。不能和其他参考素材同时使用。只给首帧时，这张图会作为一张全能参考图发送（部分上游渠道的首尾帧模式要求两张都有）。
- **长任务：** 一般 1～5 分钟出片。超过 8 分钟会返回任务 ID 而不是报错，之后用「查询视频任务」取回。工作流里也可以关掉「等待出片」，立即拿到任务 ID，后面的节点再取。工具节点超时建议设 10 分钟以上。
- **输出：** 视频文件（`files`）、JSON（`task_id`、`status`、`model`、`credits_consumed`、`video_url`）和一句文字说明。`video_url` 是临时链接，需要长期保存请保存文件。超过 50 MB 的视频不作为文件返回，只给临时链接。

## 计费

- 按输出视频的秒数扣 ModelHub 积分；**参考视频也计费**：参考视频总时长向上取整到整秒，并入输出时长一起计费。单价取决于模型和分辨率，实时价格见 [modelhub.cc/models](https://modelhub.cc/models)（JSON：`https://modelhub.cc/v1/models`）。
- 被拒绝的请求（HTTP 4xx）和失败的任务不扣费。
- 「查询视频任务」免费。

## 网络要求

- 需要能用 HTTPS 访问 `modelhub.cc`（API）和 `media.modelhub.cc`（成片下载）。下载成片时不带 Key；插件拒绝从内网地址下载。

## 隐私

见 [PRIVACY.md](../PRIVACY.md)。简单说：提示词、图片和参数会发给 ModelHub 用来生成视频，插件本身不保存任何数据。
